PHASE 1 ~ 7 개요

Phase1
- 설명: 서버를 처음 실행했을 때 홈페이지 UI(정적 페이지)만 보입니다. 디자인 확인용이며 어떠한 기능(로그인, 데이터 표시, 인터랙션)이 없어야 합니다.
- 완료 기준 체크리스트:
  - 서버 실행 시 루트 경로에서 기본 UI가 노출된다.
  - 버튼/링크는 시각적으로 보이지만 클릭 시 아무 동작을 하지 않는다.
  - 반응형(데스크톱/모바일) 레이아웃 확인용 샘플이 포함된다.

Phase2
- 설명: 상단 네비게이션 바에 ‘부산 게시판, 지도, 대시보드, 축제 캘린더, 북마크’가 보이며, 홈에서도 각 항목의 요약을 확인할 수 있습니다. 각 메뉴는 아직 링크로만 표시되거나 SPA 라우트 연결만 되어있어도 됩니다.
- 완료 기준 체크리스트:
  - 네비게이션 바에 5개 메뉴가 표시된다.
  - 홈 페이지에 각 메뉴의 간단 요약(카드 또는 링크)이 존재한다.
  - 메뉴 클릭 시(또는 라우팅 시) 해당 라우트로 이동하거나 플레이스홀더가 표시된다.

Phase3
- 설명: ‘부산 게시판’은 SPA 내에서 CRUD 기능을 갖습니다. 사용자는 게시글을 작성(Create), 조회(Read), 수정(Update), 삭제(Delete)할 수 있어야 합니다. 데이터는 우선 `docs/data`의 mock JSON을 사용합니다.
- 완료 기준 체크리스트:
  - 게시물 목록 보기, 상세 보기 동작
  - 게시물 작성 폼(제목, 본문, 태그 등) 제공 및 저장(로컬 mock 데이터 반영)
  - 게시물 수정/삭제 기능 동작
  - 입력 검증(필수 항목) 및 간단한 에러 처리

Phase4
- 설명: ‘지도’ 메뉴는 부산 지도가 보이며, 범주(음식점, 축제/공연/행사, 문화시설, 레포츠, 숙박, 쇼핑, 여행코스)를 선택해 해당 POI들을 볼 수 있습니다. 각 범주 토글로 레이어를 켜고 끌 수 있어야 합니다.
- 완료 기준 체크리스트:
  - 기본 부산 지도(지도 라이브러리 사용 또는 이미지) 표시
  - 각 카테고리 버튼/토글로 POI 레이어 표시/숨기기
  - POI 클릭 시 간단한 정보 팝업 또는 상세 보기 연결
  - POI 데이터는 `docs/data`의 mock JSON으로 로드

Phase5
- 설명: ‘대시보드’는 부산 관광 데이터와 커뮤니티 현황을 결합한 통계(표와 차트)를 제공합니다. 표/차트 라이브러리를 사용해 기본 통계 시각화를 구현합니다.
- 완료 기준 체크리스트:
  - 표(데이터 테이블)로 주요 지표 표시
  - 차트(예: 막대/원형/라인)로 시각화 표시
  - 데이터 소스는 `docs/data` 또는 mock API
  - 차트/테이블 간의 필터링(기간, 카테고리 등) 기본 동작

Phase6
- 설명: ‘축제 캘린더’는 축제/행사 일정을 달력 형태로 보여주며, 부산 권역의 축제/공연/행사 정보가 갱신일 기준으로 배치(정렬)되어야 합니다. 캘린더에서 항목 클릭 시 상세 정보를 확인할 수 있습니다.
- 완료 기준 체크리스트:
  - 달력 컴포넌트에 행사 일정 렌더링
  - 갱신일(updated_at) 기준 정렬/표시
  - 행사 클릭 시 상세 정보(장소, 시간, 설명) 노출
  - 데이터는 `docs/data` mock JSON으로 제공

Phase7
- 설명: ‘북마크’는 사용자가 북마크한 게시글을 목록으로 보여줍니다. 로그인/유저 관리가 없더라도 로컬 스토리지 등으로 북마크 상태를 유지합니다.
- 완료 기준 체크리스트:
  - 게시물 목록에서 북마크 추가/제거 기능
  - 북마크 화면에서 북마크한 게시물만 필터링하여 표시
  - 북마크 상태는 페이지 리로드 후에도 유지(localStorage)

참고: 각 Phase의 백엔드 연동은 우선 mock 데이터로 진행하고, 추후 실제 공공데이터 API로 대체합니다.

적용 상태 요약:

- Phase1: 완료 — 홈 UI(타이틀/캐치프레이즈/그래픽) 적용됨
- Phase2: 완료 — 네비게이션 및 홈 요약 카드 적용됨
- Phase3: 완료 — 게시판 CRUD 구현 (docs/data/board.json, localStorage 저장)
- Phase4: 완료 — 지도에 모든 POI 로드 및 카테고리별 색상 마커 표시
- Phase5: 완료 — 대시보드 차트/테이블 적용 (docs/data/dashboard.json)
- Phase6: 완료 — 축제 캘린더 구현 및 갱신일 기준 정렬 (docs/data/events.json)
- Phase7: 완료 — 북마크 기능 구현 및 목록 페이지 적용
